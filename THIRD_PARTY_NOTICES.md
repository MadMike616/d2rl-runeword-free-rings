# Third-party notices

The source archive includes the D2RLoader Plugin SDK 0.4.0 headers and
documentation. Its MIT license is included at
`PluginSDK/SDK-0.4.0/LICENSE` in that archive. [D2RLoader Plugin SDK](https://github.com/D2RLoader/PluginSDK)

The local game and player-lookup byte witnesses are adapted from the MIT-licensed Drop Logger and its RuffnecKk-D2RLoader-Suite reference, with the local game pointer cross-checked against Pyre-Flies' Floating Damage native contract. The state lookup call witness and stat-list identity field offsets are adapted from the MIT-licensed Buff HUD. These are native layout references, not installed hook sites.

The server client accessor and optional local player lookup witnesses use the
RuffnecKk-D2RLoader-Suite references in the Bulk Skill Point Allocation and
Equipped Item to Cube plugins.

- RuffnecKk-D2RLoader-Suite: https://github.com/RuffDood/RuffnecKk-D2RLoader-Suite
- Floating Damage native contract: https://github.com/Pyre-Flies/D2R-Mods/blob/main/plugins/floating-damage/NATIVE-CONTRACT.md
